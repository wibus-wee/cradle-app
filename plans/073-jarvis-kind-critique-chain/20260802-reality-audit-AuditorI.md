G’s “workers keep own minds / no homogenize into Cradle-turns” tracks live ownership.

4. **IRON LAW’s forbidden pattern is real Cradle doctrine** (workspace rule): close/clear user projection on empty/early native `result`, then open `origin: system` synthetic run to continue the **same** native cognition. G’s L1/L2/L11 spine correctly treats this as constitutional, not optional folklore for Kind demos.

5. **“Coding Kind” is not present product reality.** G correctly kills “co-equal to Coding Kind” as present fact. Coding workers today are runtimes/providers/delegates, not a named Kind.

6. **Ambient observes; it does not own a propose/act policy layer for the plane.** Activity → observation messages → prompt injection is real. Plane-wide steward propose / grant-gated act is not.

7. **L5 orchestration is mostly human/CLI-driven today**, with Work / Issue / Queue / Automation / Session Await as the Plan 061 L5 inventory — not a platform Kind. Seed’s “sparse cradle MCP (recall + manage_pull_request)” matches Work’s closed-loop MCP story and Plan 061’s Recall intent.

8. **Unified control-tower situation picture, Kind-scoped continuity memory, Kind grant/blast-radius, and honest platform-level delegate→receipt semantics are missing as Kind product.** Fragmented owners exist (below); the **unified steward experience** G demands does not.

9. **Narrow Kind (not monopoly organism / not second scheduler)** is consistent with live architecture: humans, Issue Agent, Automation, CLI already act across the plane; workers act without per-step Kind permission. Rejecting D’s “only organism” is reality-preserving.

10. **Open tensions T13 / T15 / T16 are correctly left open as evidence gaps**, not fake-closed — especially proto-steward reconciliation and ambient fate.

## 2. Overclaims / fiction relative to Cradle today

### 2.2 Identity rhetoric that understates what Cradle already is

- **“Without a first-class kind… Cradle collapses into a session multiplexer or a teammate board without a steward”** (§1). Strategic fear, not accurate present description. Cradle today already has Work, Issue Agent, Automation, Session Await, Thread Handoff, provider-threads, harness fragments — more than a multiplexer. Kind may still be the missing *steward identity*; claiming present collapse is fiction that makes Kind feel more necessary than inventory warrants.

### 2.3 IRON LAW / L2 language that can falsely ban live seams

- Gap #4: “IRON LAW / projection honesty **not internalized** as product law across all natives.” Partially true that the **named rule file is Claude Agent–scoped**. Overclaim if it implies Chat Runtime lacks multi-provider projection ownership — it owns run lifecycle, fact log, provider-threads, queue/steer, completion barriers across providers. What is missing is **constitutional product-law framing for Kind + every native**, not internalization of projection architecture itself.

- **L2 / anti-synthetic-continuation** must not be read as banning all `origin: system` runs. Live Chat Runtime already schedules **runtime goal continuation** as deduped follow-up **system** runs when a provider-owned continuable goal remains; provider-synthetic main-thread events also create system runs. The forbidden pattern is specific (empty/early result → clear user projection → invent system continuity for the **same** native work). G’s falsifier text is mostly careful; without an explicit carve-out, Finalizer language will be misread as outlawing goalContinuation.

### 2.4 Soft fictions / category stretches

- **“Humans already sense/propose/act” via CLI, Work, Automation, Issue Agent** — humans + these features **act/delegate/wait**; calling that Kind-shaped **propose** is metaphorical stretch. Accurate for killing monopoly; imprecise as inventory of propose loops.

- **“Control tower”** as named center-of-gravity noun — not a live Cradle module. Acceptable as constitutional metaphor only if Finalizer does not imply it already exists as an owned surface.

- **“Coding workers”** — not a live product term. Fine as constitution vocabulary if not confused with runtime catalog entities.

- Competitive **“open slot”** — G already demotes this to unproven bet (§9/§10); no further fiction if Finalizer keeps demand humility.

## 3. Underclaims — real assets G ignored that change the constitution

G’s §8/T15 nod at proto-stewards is too thin. These live assets change what “missing Kind” means:

1. **Issue Agent + Agent Interaction Runtime** — real delegation, continuation bridge, stop/undelegate into Chat Runtime, optional Work isolation. This is the strongest proto-steward / proto-delegate path. Constitution cannot treat Kind as entering an empty orchestration field; Kind must relate to this owner (absorb / command / peer / replace remains open, but **existence is not open**).

2. **Session Await** — durable external waits that resume sessions via Chat Runtime queue. Directly relevant to G’s “leave for hours / what is blocked” promise. Partial answer to felt stewardship **already ships** without Kind.

3. **Automation** — durable definitions, schedule, heartbeat vs isolation, triage inbox, explicit findings contract. Proto sense→act / clerk without Kind identity. Gap #1/#11 must not pretend this is unnamed vapor.

4. **Work closed-loop delivery** — primary thread, harness `CRADLE WORK MODE`, `manage_pull_request` as agent-facing finalization. Dual-center Choice C must admit Work is **already a durable center for coding delivery**, weak as **platform-steward ledger**.

5. **Chat Runtime `session_events` fact log + run snapshots** — existing execution truth-of-record / forensic envelope. L5/L9 “platform owns truthfulness” is not starting from zero; Kind must not invent a second truth owner that shadows this for runs.

6. **Plan 061 cognition stack (L1 Evidence → L5 Orchestration; Execution = Chat Runtime)** — authoritative layering for memory/retrieval/orchestration. Kind continuity (gap #6, T13) and “situation picture” sit **above/beside** claimed Chronicle (L2) / Recall (L3) / Harness (L4) owners. Ignoring this invites Kind to colonize memory by slogan.

7. **Harness / L4 push context** — stable runtime identity, session/work fragments, Work mode block. Kind must not be described as if no deterministic context assembly exists.

8. **Provider-native threads / Codex crew** — live bypass path for “strategy inside provider thread” (T12). Not merely future risk.

9. **Runtime goalContinuation and provider-synthetic system runs** — must appear in reality inventory so L1/L2 falsifiers stay precise.

10. **Jarvis ambient observation pipeline + preferences + history tabs** — observe half of observe→propose exists as product. Gap #1 should be “no plane steward propose/act policy,” not “no Jarvis loop.”

11. **Thread Handoff** (feature-flagged) — explicit provider-to-provider transfer with provenance. Proto receipt/handoff semantics.

12. **Partial return-from-absence UX** — completed-run notification projection, Await progress observations, status waiting states. Felt-stewardship promise is not inventing the problem from a blank UI; Kind must outdo these fragments, not ignore them.

**Constitutional implication:** Kind is missing as **elevated continuous steward identity + grant policy + plane-wide propose**, not as the first orchestration or durability machinery on the platform.

## 5. Mandatory reality corrections for Finalizer

Non-negotiable inventory corrections before the constitution is decision-ready. Still no implementation advice — only reality framing.

1. **Kill the L-number collision.** Rename constitutional laws (e.g. Law 1…Law 14, or `CL-1…`) **or** always prefix `Stack L#` vs `Law #`. Leaving G’s L1–L14 beside Plan 061 L1–L5 is unacceptable fiction-by-ambiguity.

2. **State Cradle’s present inventory without collapse rhetoric.** Cradle is already a local multi-runtime control plane with Work, Issue Agent, Automation, Session Await, Thread Handoff, Chat Runtime fact/projection machinery, and HiJarvis ambient — **missing a narrow platform Kind**, not missing all durability/orchestration.

3. **Rewrite absolute gap #1 / #2 / #5 / #7** to the precise absences:
   - no Kind-scoped plane-wide **propose** loop;
   - no **unified, honesty-labeled** situation picture for stewardship;
   - no Kind-scoped **grant / blast-radius** dial (preferences ≠ grants);
   - Work is durable for **coding delivery**, not yet a general **steward obligation ledger**.

4. **Name proto-stewards as existing assets in the identity / gap sections**, not only as T15 “later.” Minimum named set: Issue Agent (+ Agent Interaction Runtime), Automation, Session Await, Thread Handoff, HiJarvis ambient. Relationship remains open; existence does not.

5. **Carve L2/IRON LAW against live system runs.** Forbidden = empty/early native completion → close user projection → open system-origin projection to continue the **same** native cognition. Not forbidden by that law alone = provider-owned goalContinuation system runs, provider-synthetic event runs, ordinary queue drain. Finalizer must say this in one plain sentence.

6. **Promote Plan 061 stack as binding reality for memory/orchestration vocabulary.** Kind continuity and situation picture must be described as **not** Chronicle ambient sludge, **not** harness push, **not** Recall-by-default, **not** a second run fact log — without designing the seam (T13 can stay open).

7. **Disambiguate live Jarvis vocabulary once, hard:** `surfaces: jarvis`, `jar-core`, System Agent, HiJarvis ambient, Jarvis preferences/popover ≠ Agent Kind. `runtimeKind` ≠ Kind.

8. **Correct IRON LAW internalization claim:** Claude-scoped named Iron Law + multi-provider Chat Runtime projection architecture exist; what Kind still lacks is **product-law extension that forbids Kind-justified exceptions on any native** — not “natives have no projection honesty.”

9. **Keep demand humility** (G §9/§10 already good): steward slot empty ≠ steward demand proven. Do not re-inflate “missing product identity” into market validation.

10. **Felt-stewardship promise must compare against existing return-from-absence fragments** (Await, notifications, triage, status waits). Success criterion stays valid; baseline is not zero.
