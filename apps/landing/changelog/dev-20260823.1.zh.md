> Cradle 现在可以跨设备工作，并将复杂的 Agent 输出转化为可复用的交互式视图。

## ✨ New

- Cradle Fabric 将已注册设备连接为经过身份验证的加密设备网络，可在本地应用中访问远程 Workspace、文件、聊天和 Session。
- Agent Artifacts 支持 Agent 创建和持续更新交互式仪表盘、报告、图表与表格，在聊天旁打开，并可将操作继续发送回会话。
- Usage 仪表盘支持合并可访问 Fabric 设备的 token、费用和运行时数据，并展示各设备明细与不可用状态。
- 同一仓库的 Workspace 现在会跨设备归组，侧边栏中可直接查看设备和仓库上下文。
- 现在可以选中消息文本并直接引用到聊天 Composer 中。
- Codex Session 新增 `/fast` 命令，无需离开聊天即可切换快速模式。
- Chronicle 现在会根据会议和语音活动控制被动录音，使用更小的生产媒体格式，并提供更安全的跨 Session 说话人档案及重命名、分配和删除控制。
- 插件现在可以订阅保护隐私的代码活动事件，且不会收到文件内容或绝对路径。

## 💎 Improvements

- Plugin Center 安装流程采用更清晰的分步引导，提供更丰富的预览和进度状态、更完善的已安装插件操作，以及可见的激活失败信息。
- Artifacts 组件套件重新设计，新增文档布局、图表、指标、表格和语义化主题，并兼容已保存的旧版源码。
- OpenCode 提问现在会显示为可交互的 Composer 表单；Full Access Session 会自动批准符合条件的权限请求。
- Diff Review 的讨论串与 Composer 现在会跟随应用主题，并采用更清晰的讨论样式。
- 运行时详情新增 Kimi 子 Agent 模型与思考强度、Codex 账户用量与诊断，以及更新后的 Claude 上下文用量。
- macOS 新增原生 Settings 与 Check for Updates 菜单操作；Windows 可在无需管理员权限的情况下将 Cradle CLI 安装到用户 PATH。
- Windows 标题栏按钮现在保留原生悬停、点击和 Snap Layout 行为；macOS 编辑器与 Finder 操作使用更清晰的原生图标。
- Linux Release 现在提供 AppImage、DEB 和 RPM 包，并支持根据已安装包类型进行应用内更新。
- DMG 安装引导更加清晰，桌面安装包体积也进一步缩小。

## ⚡ Performance

- 桌面端 API 与事件流量现在通过主进程的有界连接处理，避免多窗口中的长连接阻塞普通请求。
- Session 启动、搜索索引、分页、运行时状态和服务器事件传输均增加边界控制，在大型 Workspace 与长时间聊天中表现更稳定。

## 🐞 Fixes

- 修复后台同步与流式回复交叉时，正在响应的 Session 消失或状态回退的问题。
- 修复 Provider 进程重启后，已持久化 Codex Thread 在回滚等操作中出现 `thread not found` 的问题。
- 修复 Quick Question 丢失现有聊天上下文，以及新聊天中的 Bang 命令被发送给模型而非本地执行的问题。
- 修复已发现的 Provider 模型目录被写入 Custom Models 的问题；实时模型刷新也更加稳定且支持搜索。
- 修复 Claude 流式回复最终用量统计不足，以及本地 Fabric Node 在设备网络总量中重复计数的问题。
- 修复 Workspace Session 列表更新不及时、Session 行只有部分区域可点击，以及已读错误仍长期显示为侧边栏提醒的问题。
- 修复 Diff 与侧边栏滚动异常，以及 App Header 切换图标尺寸不一致的问题。
- 修复配置代理后 GitHub 请求失败，以及 Pull Request 刷新仍返回旧数据的问题。
- 修复后台标签页创建竞态，以及历史 Artifact 而非新建 Artifact 自动打开面板的问题。
- 修复移动端后台活动导致不必要耗电的问题。
