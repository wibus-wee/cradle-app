> From Agent-authored personal Plugins to cross-device mobile work, Cradle now connects more of the complete workflow.

## ✨ New

- Agents can now create and install personal Plugins. Cradle stores immutable build snapshots, presents permissions and runtime layers for review in the originating chat, and activates Server, Web, and Desktop capabilities only after explicit approval.
- Personal Plugins support safe updates: failed builds preserve the previous version, while content changes revoke old grants and require another review before activation.
- ACP runtimes now support local and remote agents, authentication and recovery, tool calls, terminals, runtime settings, and complete capability presentation.
- Mobile can now enroll as a Controller through Cradle Fabric, switch Nodes, and access remote workspaces, chats, and sessions.
- Settings includes a new Storage Manager for inspecting session usage, purging transcripts or full sessions, collecting orphaned files, and compacting the local database.
- Chat runtimes add native live controls and diagnostics. Codex providers can also configure inherited state, feature flags, common settings, and advanced native configuration independently.
- Codex authentication failures now provide an actionable recovery path in chat, while Claude reports reasoning-token usage separately.
- Kimi discovers available models per provider target and lets users inspect and control background tasks directly.
- Background Activity can now surface dismissible footer notices, including Codex quota reset reminders.
- Fabric adds management for approved Controllers and allows reviewed Desktop Renderer Plugins to be deployed safely.

## 💎 Improvements

- Desktop session tear-off windows warm their content and follow the pointer as soon as it crosses the window boundary, reducing blank states and making dragging feel more native on macOS and Windows.
- Workspaces for the same repository are merged across devices, with machine selection moved into the composer; missing Git identities are also backfilled automatically.
- Usage remembers its time range, exports CSV, and refreshes local or fleet data. Download Center adds average throughput, completion estimates, and remembered views.
- The Command Palette can start Work, reopen the last closed surface, copy the workspace path, and open a review of the active workspace changes.
- Pull Requests, Diff Review, Runtimes, Skills, Plugins, transfers, Kanban, and global search add filter counts, clear actions, keyboard navigation, and clearer recovery from empty states.
- Mobile adds workspace file browsing, search, preview, and sharing, plus Pull Request refresh, Checks and changed-file links, GitHub handoff, and preservation of failed review drafts.
- New Chat surfaces recent project sessions. Session Notes show save status and prevent older autosaves from overwriting newer typing.

## 🐞 Fixes

- Fixed the Web app getting stuck when the server was temporarily unreachable during startup; reconnection can now recover in place.
- Fixed persisted session queues not resuming after restart, stale activity ordering, and active Codex title generation being routed to the wrong provider.
- Fixed Plugin review cards becoming non-interactive in overlays, providers not recovering after activation, and inaccurate rollback state after failed updates.
- Fixed macOS session tear-offs drifting away from the pointer and Command-Q being confused with programmatic quit.
- Fixed provider model inventories disagreeing across selectors, Codex planning being unintentionally disabled, and OpenCode question bridging failing.
- Fixed GitHub integration failures behind configured proxies or for repositories not yet installed, with better in-place retry for Git panels and route errors.
