> 从 Agent 创建个人 Plugin 到跨设备移动办公，Cradle 的完整工作流进一步打通。

## ✨ New

- Agent 现在可以创建并安装个人 Plugin；Cradle 会保存不可变构建快照，在原始聊天中展示权限与运行层审查，并仅在明确批准后激活 Server、Web 和 Desktop 能力。
- 个人 Plugin 支持安全更新：失败的构建会保留上一版本，内容变化会撤销旧授权，并要求重新审查后再激活。
- ACP 运行时现已支持本地与远程 Agent、身份验证与恢复、工具调用、终端、运行时设置和完整能力展示。
- 移动端现在可以通过 Cradle Fabric 注册 Controller、切换 Node，并访问远程 Workspace、聊天和 Session。
- Settings 新增 Storage Manager，可查看 Session 占用、清理转录或完整 Session、回收孤立文件，并压缩本地数据库。
- 聊天运行时新增原生实时控制与诊断；Codex Provider 还可分别配置继承状态、功能开关、常用设置和高级原生配置。
- Codex 身份验证失败现在会在聊天中提供可操作的恢复入口；Claude 会单独展示推理 token 用量。
- Kimi 会按 Provider Target 发现可用模型，并允许直接查看和控制后台任务。
- 后台活动现在可在 Footer 中显示可关闭通知，并支持 Codex 配额重置提醒。
- Fabric 新增已批准 Controller 的查看与管理，并允许在审核后安全部署 Desktop Renderer Plugin。

## 💎 Improvements

- 桌面 Session 拖出窗口会预热内容并在越过窗口边界时立即跟随指针，减少白屏和等待感，macOS 与 Windows 的拖动体验更接近原生窗口。
- 同一仓库的多设备 Workspace 会合并为一条记录，并在 Composer 中选择执行机器；缺失的 Git 身份也会自动补全。
- Usage 会记住时间范围，支持 CSV 导出及本机/设备网络刷新；Download Center 新增平均速度、完成时间预估和视图记忆。
- Command Palette 现在可以直接启动 Work、恢复最近关闭的界面、复制 Workspace 路径，并进入当前 Workspace 的改动审查。
- Pull Request、Diff Review、Runtime、Skill、Plugin、资源传输、Kanban 和全局搜索增加筛选计数、清空操作、键盘导航和更明确的空状态恢复。
- 移动端新增 Workspace 文件浏览、搜索、预览与分享，并可刷新 Pull Request、查看 Checks 和改动文件、跳转 GitHub，以及在失败后保留 Review 草稿。
- New Chat 会展示最近的项目会话；Session Notes 新增保存状态，并避免较早的自动保存覆盖正在输入的内容。

## 🐞 Fixes

- 修复 Web 启动时服务器暂不可用会卡住的问题，现在可直接恢复连接。
- 修复应用重启后持久化 Session 队列无法继续、会话活动排序滞后，以及活跃 Codex 会话标题生成路由错误的问题。
- 修复 Plugin 审查卡在浮层中无法操作、激活后 Provider 未恢复，以及更新失败时回滚状态不准确的问题。
- 修复 macOS Session 拖出窗口偏离指针，以及 Command-Q 与程序化退出行为混淆的问题。
- 修复 Provider 模型清单在不同选择器之间不同步、Codex 计划工具被意外禁用，以及 OpenCode 提问桥接失效的问题。
- 修复配置代理或尚未安装仓库时 GitHub 集成失败，并改进 Git 面板和路由错误的就地重试。
