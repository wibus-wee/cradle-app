> 从代码评审到临时终端，Cradle 的工作流更完整，也更加可靠。

## ✨ New

- MCP 设置新增官方 Registry 发现与搜索，可直接浏览并安装可用服务器。
- Workspaces 支持将已注册的本地文件夹组合为多文件夹工作区。
- Diffs 重做为以仓库为入口的代码评审界面，列表展示状态、作者、分支、检查、标签与未读进度。
- Browser 注释浮层更加稳定，Design Inspector 新增更多设计属性检查能力。
- 在工作区聊天输入 `!` 可打开临时 Cradle PTY，输出可以丢弃或作为清理后的会话记录发回聊天。
- 聊天 Composer 新增 Review、Commit、Push 意图，以及 commit-group 指令和可点击的文件链接。
- Provider 设置改为引导式配置流程，并提供 Provider 预设、图标和本地配置扫描。
- 桌面端新增数据备份与恢复能力。
- Review 支持渲染代码评论指令，Codex 评审改用原生 Review API。
- 聊天上下文用量弹窗现在会展示运行时用量窗口、剩余比例和重置时间。
- 创建 Work 时可以明确选择基准分支，避免从错误的分支开始工作。

## 💎 Improvements

- 上下文用量详情支持按 Provider 分解 token 消耗，并在运行时不提供详细分解时显示汇总用量。
- Provider 模型列表优先使用缓存数据，打开模型选择器更快、更稳定。
- 侧边栏支持按工作区、更新时间、状态和环境分组，并可按更新时间、状态、Pull Request、来源及远程环境筛选；新增最近会话排序。
- Kanban Issue 详情强化了活动记录、Sub-issues、属性导航、状态上下文和悬停预览。
- Session Await 的 JavaScript 卡片和分屏交互更清晰，等待结果更容易查看和管理。
- Codex、Kimi 与 OpenCode 运行时信息更完整：支持 Kimi 用量与中断原因、Codex Plan 类型、Skill 图标和插件来源展示。
- 导入外部会话时会发现更多 Claude、Codex Provider 目录和 `CRADLE_DATA_DIR` 中的运行时记录，并自动去重。
- Provider 身份、贡献认证和双端点配置更加明确，DeepSeek 与 Moonshot 的多端点设置更易管理。
- MCP、聊天和 Provider 设置补充中文、日文、西班牙文文案；浮层阴影、焦点样式和桌面菜单栏图标也得到统一调整。
- Streamdown 支持属性指令，代码高亮在浅色主题下能保留正确颜色。

## 🐞 Fixes

- 修复资源面板遗漏部分 Codex、Kimi、OpenCode 运行时主机的问题。
- 修复受保护的图片附件在聊天中重复加载的问题。
- 修复 Provider 警告没有以内联方式显示在聊天中的问题。
- 修复网页应用外壳溢出导致页面滚动异常的问题。
- 修复远程 Relay 隧道恢复、WebSocket 关闭和大 payload 传输中的可靠性问题。
- 修复 GitHub Agent 生成重复 Pull Request 正文区块的问题。
- 修复 Work 缺少主会话时列表消失的问题。
- 修复 CLI 打包后无法正确携带运行时的问题。
- 修复使用票据认证的 WebSocket 连接无法正常升级的问题。
- 修复聊天 Quick Question 无法复用上下文及触发 Zod 错误的问题。
- 修复多个会话同时刷新 GitHub App token 时的重复请求与竞态问题。
- 修复 Session Await 等待 GitHub 分支保护检查时阻塞 CI 的问题。
- 修复终端会话重连时重复建立 WebSocket 导致连接不稳定的问题。
- 修复 Work 提交被拒绝后聊天草稿丢失的问题。
