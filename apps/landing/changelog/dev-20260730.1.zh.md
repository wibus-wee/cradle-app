> 用量有了模样，窗口有了呼吸，断开的对话也能在原地醒来。

## ✨ New

- 全新用量面板：新增工具用量视图、成本效率分析与时间范围筛选，可查看每个工具与 Provider 的消耗。
- 看板支持分组视图控制与 Issue 手动排序。
- 分屏视图通用化，所有面板均可自由拆分组合。
- 终端视图可显示 CLI 活动状态，Kimi CLI 等 TUI 会话会被捕获并保持存活，标题自动识别。
- 应用内发布通告与新功能提示：新版本可在右下角弹出更新摘要卡片。
- Work 归档时自动清理其管理的 Git Worktree。
- Pull Request 列表页支持筛选。
- 支持通过 GitHub App 获取用户身份。

## 💎 Improvements

- **聊天流式架构重构**：整条流式管线重建为基于消息快照的机制（新的 `@cradleapp/ai-sdk`），服务端以快照序列器取代逐条回放，转录内容有界保留。中断后恢复更快、更完整，消息外壳即时补水渲染，长时间会话的内存与存储占用也更可控。
- 转向指令（Steer）队列持久化，会话运行时元数据自动注入，取消操作更可靠。
- Provider 凭证刷新统一协调，多个会话共享凭证时不再互相冲突。
- Relay V2 传输层延迟与效率优化。
- 数据库自动维护，无需手动干预。
- 下载管理移入设置页，界面导航更简洁。
- 开发者工具新增运行时活动与 Await 检查面板。

## 🐞 Fixes

- 修复 Claude Agent 返回空结果后丢失用户消息的问题。
- 修复 Codex 空闲会话被误回收及 MCP 调用环境变量泄漏的问题。
- 修复 Relay WebSocket 断开时的崩溃。
- 修复桌面端网络访问模式下 CRADLE_AUTH_TOKEN 丢失的问题。
- 修复工作区中 Diff 与终端未正确使用 Worktree 的问题。
- 修复侧边栏 Pull Request 状态与右侧面板偏好未能保留的问题。
