> From code review to temporary terminals, Cradle now covers more of the workflow with greater reliability.

## ✨ New

- MCP settings now include official Registry discovery and search, so available servers can be browsed and installed directly.
- Workspaces can now combine registered local folders into a multi-folder workspace.
- Diffs has been rebuilt as a repository-first code review surface, with status, author, branch, checks, labels, and unread progress visible in review lists.
- Browser annotation overlays are more reliable, and the Design Inspector now exposes more design properties.
- Type `!` in a workspace chat to open a temporary Cradle PTY; its output can be discarded or sent back as a scrubbed chat transcript.
- The chat Composer now supports Review, Commit, and Push intents, plus commit-group directives with clickable file links.
- Provider setup now uses a guided flow with provider presets, icons, and local configuration scanning.
- Desktop now supports data backup and restore.
- Reviews can render code-comment directives, and Codex reviews now use the native Review API.
- The chat context usage popover now shows runtime usage windows, remaining percentages, and reset times.
- New Work creation now lets you explicitly choose the base branch, so work starts from the intended branch.

## 💎 Improvements

- Context usage details can now break token consumption down by provider, with a runtime total when detailed sections are unavailable.
- Provider model lists prefer cached data, making the model picker faster and more reliable to open.
- The sidebar can group sessions by workspace, recency, status, or environment, and filter by recency, status, pull request, source, and remote environment; recent-session ordering is also available.
- Kanban issue details now have richer activity history, sub-issue views, property navigation, status context, and hover previews.
- Session Await now has clearer JavaScript cards and split-pane interactions for viewing and managing wait results.
- Codex, Kimi, and OpenCode runtime information is more complete, including Kimi usage and interrupt reasons, Codex plan types, skill icons, and plugin provenance.
- External session imports now discover more Claude and Codex provider directories plus runtime records under `CRADLE_DATA_DIR`, with automatic deduplication.
- Provider identity, contribution authentication, and dual-endpoint configuration are clearer, including easier multi-endpoint setup for DeepSeek and Moonshot.
- MCP, chat, and provider settings now include Chinese, Japanese, and Spanish copy; floating shadows, focus styles, and desktop menu bar icons are more consistent.
- Streamdown now supports attribute directives, and syntax highlighting preserves the correct colors in light themes.

## 🐞 Fixes

- Fixed the resource panel omitting some Codex, Kimi, and OpenCode runtime hosts.
- Fixed protected image attachments being loaded repeatedly in chat.
- Fixed provider warnings not appearing inline in chat.
- Fixed abnormal page scrolling caused by overflow in the web app shell.
- Fixed reliability issues during remote Relay tunnel recovery, WebSocket teardown, and large-payload transfer.
- Fixed GitHub Agent creating duplicate sections in pull request bodies.
- Fixed the Work list disappearing when a primary session was missing.
- Fixed packaged CLI builds from failing to carry their runtime correctly.
- Fixed ticket-authenticated WebSocket connections failing to upgrade.
- Fixed Quick Question failing to reuse chat context and triggering a Zod error.
- Fixed duplicate and competing GitHub App token refreshes when multiple sessions refresh at once.
- Fixed Session Await blocking CI while waiting for GitHub branch protection checks.
- Fixed unstable terminal sessions caused by duplicate WebSocket reconnects.
- Fixed chat drafts being lost after a Work submission was rejected.
