> Cradle can now work across devices and turn complex agent output into reusable interactive views.

## ✨ New

- Cradle Fabric connects enrolled devices into an authenticated, encrypted fleet, making remote workspaces, files, chats, and sessions available from the local app.
- Agent Artifacts let agents create and revise interactive dashboards, reports, charts, and tables that open beside chat and can send actions back to the conversation.
- The Usage dashboard can merge token, cost, and runtime data across reachable Fabric devices, with a per-device breakdown and unavailable-device status.
- Workspaces from the same repository are now grouped across devices, with machine and repository context visible in the sidebar.
- Selected message text can now be quoted directly into the chat composer.
- Codex sessions include a `/fast` command for switching fast mode without leaving chat.
- Chronicle now gates passive audio capture around meetings and speech, stores smaller production media, and supports safer cross-session speaker profiles with rename, assignment, and deletion controls.
- Plugins can subscribe to privacy-preserving code activity events without receiving file contents or absolute paths.

## 💎 Improvements

- Plugin Center installation now uses clearer guided steps, richer previews and progress states, better installed-plugin actions, and visible activation failures.
- Artifacts have a redesigned component kit with document layouts, charts, metrics, tables, semantic themes, and compatibility for previously saved sources.
- OpenCode questions now render as interactive composer forms, while full-access sessions automatically approve eligible permission requests.
- Diff review threads and composers now follow the active app theme with clearer discussion styling.
- Runtime details now include Kimi child-agent model and thinking effort, Codex account usage and diagnostics, and refreshed Claude context usage.
- macOS adds native Settings and Check for Updates menu actions, while Windows can install the Cradle CLI into the user PATH without administrator access.
- Windows caption buttons now preserve native hover, click, and Snap Layout behavior; macOS editor and Finder actions use clearer native icons.
- Linux releases now include AppImage, DEB, and RPM packages with package-aware in-app updates.
- The DMG installation experience is clearer, and desktop packages are smaller.

## ⚡ Performance

- Desktop API and event-stream traffic now runs through bounded main-process connections, preventing long-lived streams in multiple windows from blocking ordinary requests.
- Session startup, search indexing, pagination, runtime state, and server event delivery are bounded for more predictable performance in large workspaces and long-running chats.

## 🐞 Fixes

- Fixed streaming sessions disappearing or reverting when background synchronization crossed an active response.
- Fixed persisted Codex threads failing with `thread not found` after the provider process restarted, including rollback and other thread operations.
- Fixed Quick Question losing its existing chat context and new-chat Bang commands being sent to the model instead of running locally.
- Fixed discovered provider catalogs being copied into Custom Models; live model refresh is also more resilient and searchable.
- Fixed final Claude streaming usage being undercounted and the local Fabric node being counted twice in fleet totals.
- Fixed stale workspace session lists, partially clickable session rows, and acknowledged errors remaining as permanent sidebar alerts.
- Fixed diff and sidebar scrolling regressions, plus inconsistent header toggle icon sizing.
- Fixed GitHub requests failing behind configured proxies and pull request refreshes returning stale data.
- Fixed background tab creation races and Artifact panels reopening for historical rather than newly created Artifacts.
- Fixed mobile background activity causing unnecessary energy use.
